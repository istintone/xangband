## 3.2 系統の設計意図

→ 数値は [参照表](reference/lineages.md)

8種。本家の種族と同じく **能力値補正・ヒットダイス・経験値倍率・技能・固有フラグ**を持つ。

| 系統 | 設計上の役割 |
|---|---|
| **地球系人類** | 基準点。何にも秀でず、何にも足を引っ張られない。経験値倍率が最も低い |
| **重力適応体** | 重装前提。重い装備を苦にしないが、細かい作業が苦手 |
| **軌道生まれ** | **減圧を恐れない**。気密の心配が要らない代わりに打たれ弱い |
| **合成体** | 毒・被曝が無効で食事も不要。代わりに**電力が尽きると止まる** |
| **拡張知性** | 知覚と隠密に特化。見えないものの気配を掴む |
| **改造体** | 汚染に強い。HP が最も高く、統率が最も低い |
| **義体化人類** | **インプラント枠+1**。装備で組み上げるビルド向け |
| **未登録個体** | 能力値がラン毎に大きく振れる。経験値倍率が最も高い。**当たり外れ**が identity |

**設計方針**: 各系統に「これができる / これができない」を1つずつ明確に持たせる。
汎用的に少し強い系統を作らない。

## 3.3 ロールの設計意図

→ 数値は [参照表](reference/roles.md)

8種。**サブシステム3系統**(精神系=集中 / 機械系=帯域 / 生体系=血中濃度)のいずれか、
または無しを持つ。

**両極が成立することが最重要**(本家と同じ):

- **装備で戦う極**: 突撃兵(能力なし・HP最高) / 狙撃手(射撃特化)
- **能力で戦う極**: 念導者(装備が乏しくても戦える・打たれ弱い) / 接続者(M4の電脳層専門)
- **中間**: 工作員・異種生物学者・潜行者・回収屋がその間を埋める

能力値は **statOrder の上位から 17/16/15/12/11/10 を配る**([[D-41]])。
完全ランダムにすると「主能力値が 8 の念導者」ができ、そのランが成立しなくなるため。

## 3.4 敵の設計意図

→ 数値は [参照表](reference/monsters.md)

系統5本。それぞれに「何が効いて何が効かないか」を持たせる。

| 系統 | 性格 | 弱点 / 耐性 |
|---|---|---|
| **感染体** | 群れる。汚染を撒く。近接主体 | 火に弱い。数で押してくる |
| **自律機械** | 高AC・遠隔。命令を実行し続けている | **対機械弾頭**が効く。毒・精神・放射が無効 |
| **異星生物** | 変則的な移動と攻撃。耐性が読みにくい | 個体差が大きい |
| **人間** | 装備を落とす。逃走して仲間を呼ぶ | 素直に効く。ドロップが良い |
| **異常** | 深層専用。精神攻撃と現実改変 | **スレイが効かない**([[D-92]])。電磁・毒素・放射も無効 |

- **《異常》だけはスレイ(系統への倍率)を受け付けない**([[D-92]])。
  スレイは「相手が何であるか」に賭ける刻印だが、異常は**分類できないもの**なので当たらない。
  通るのはブランド(属性)のうち**高熱・極低温・腐食**だけ。
  深部は `aberrant` が最多(深度70-100 で 10/21体)なので、
  これが無いと**終盤は「対異常を引いたか」の抽選**になる ―― 実測で《門番》が3手で沈んでいた。

- **ユニーク**は固有名を持ち、**1ランに1体**。護衛(escort)を伴い、倒すと二度と出ない。
- 敵は**眠った状態で配置**される([[D-40]])。隠密で忍び寄るか、騒がしく突っ込むかの選択が生まれる。
- **群れる敵(GROUP)の個体火力は、同深度の単独敵の中央値の半分以下**([[D-43]])。
  群れは最大4体になるので、個体を単独敵と同じ火力にすると総火力が4倍になる。
  **群れの怖さは総量であって個体の強さではない。**
  この規則は `src/tests/run.js` のデータ検査で強制している ―― M3b の時点で
  6種中5種が違反しており、自動プレイの死因の50%を[[mon:infested-crew]]1種が占めていた。
  決定を文章だけで持つと data 側で守られない。

## 3.5 アイテムの設計指針

→ 数値は [参照表](reference/items.md) / [改修品](reference/egos.md) / [固有機材](reference/uniques.md)

- **刻印「加速」は極めて希少**にする。速度の価値を守るため([[D-04]])。
- **固有機材には汚染ファームを一定数同居**させる。強いだけの装備を作らない。
- **セル**は最も基本的な消耗資源。序盤から常に足りない状態に置く。
- 射出器の**倍率は最後に掛かる**ので、良い射出器を手に入れた瞬間に戦い方が変わる。

## 3.6 交易区(店)6区画

| 区画 | 扱い | 役務 | 本家の対応 |
|---|---|---|---|
| 補給所 | 携行食・セル・基本アンプル | — | General Store |
| 兵装廠 | 兵装・射出器・弾体 | — | Weaponsmith |
| 装甲廠 | スーツ・装甲板 | — | Armoury |
| 調剤室 | アンプル各種 | — | Alchemist |
| 情報屋 | プロトコル | **解析 / 治療** | Magic shop |
| **工房** | インプラント・リンク・ライト | **修理**(移植は M4) | (Black market の位置) |

- 在庫は**到達最深度に応じて品揃えが伸びる**。母船に戻るたびに一部が入れ替わる。
- 買値は1個あたり。**売値は買値の 1/4** — 店を稼ぎ手段にしない。
- **統率**で買値が下がる(本家の CHR と同じ役割)。
