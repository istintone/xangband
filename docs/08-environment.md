# 8. 惑星環境の設計

> **M3 の中核。** サイトを「見た目違いの同じダンジョン」にしないための機構。
> 勝利条件が環境に接続している(§[[doc:endgame]] §7.2)ので、ここが設計の背骨になる。

---

## 8.1 現状の問題

M2 時点で `seal`(気密) と `exposure`(被曝) は**値として存在するが、
それを要求する環境が無い**。装備に付いた数字が何も参照していない。

> **環境を「敵と同格の脅威」にする。** ダメージ源としてではなく、
> **装備の選択を強制するもの**として設計する。

---

## 8.2 舞台 ― 星系

すべては**ひとつの恒星系**の中で起きる。移動距離を物語に使わない。

| 天体 | サイト | 位置 |
|---|---|---|
| 観測目録 **4471-c**、通称《灰》 | **灰の地表** / **異星遺跡** / **超高層《尖塔》** | 惑星本体 |
| 漂流物 **《方舟》** | **漂流艦《方舟》** | 《灰》の低軌道 |
| 母船 **《アンカー》** | 拠点(深度0) | 《灰》の低軌道 |
| — | **《起源》** | 《灰》の地殻より下 |

### 《灰》という惑星
- 大気は薄い。**気圧は人が耐えられる下限のあたり**で、場所によって割り込む。
- 恒星風を遮る磁場が弱く、**地表は常に被曝**する。
- 自転周期が長く、**昼夜が探索の単位になる**。
- 地表の大半は灰。何かが燃えた後の灰ではなく、**何かが削られた後の灰**。

### 4サイトの垂直関係
```
        軌道   ── 母船《アンカー》 / 漂流艦《方舟》
     ─────────  大気圏
        地表   ── 灰の地表 / 超高層《尖塔》(地表から上へ伸びる)
     ─────────  地殻
        地下   ── 異星遺跡
     ─────────
        深部   ── 《起源》
```

**「深度」は物理的な深さではなく、《起源》への近さ**として統一されている
([[D-03]])。尖塔は上へ登るのに深度が増える ―― これは意図的な違和感で、
ログ断片で「尖塔は地下構造の反転である」と示唆する。

## 8.3 環境モデル ([[D-46]])

階層は **7つの環境値**を持つ。すべて `sites.json` のサイト定義から生成時に決まる。

```js
lv.env = {
  atmosphere:   0..100,   // 気圧。100 が標準大気
  temperature:  -100..200,// 温度(摂氏相当)
  radiation:    0..10,    // 放射線量
  contamination:0..10,    // 生体汚染
  gravity:      0.0..3.0, // 重力(1.0 が標準)
  surveillance: 0..10,    // 監視密度
  ambient:      0..3      // 環境光。0 = 完全暗黒
}
```

### 各値が引き起こすもの

| 環境値 | 閾値を超えると | 対抗手段 |
|---|---|---|
| **atmosphere** 低 | **減圧**: 毎ターン継続ダメージ + 発声系の能力が使えない | **気密(seal)** |
| **temperature** 高/低 | 高熱/凍結ダメージ。装備の損傷 | 刻印《耐熱》《耐寒》 |
| **radiation** | **被曝**が蓄積。閾値ごとに能力値が一時低下 | 刻印《耐放射》、遮蔽物の陰 |
| **contamination** | **汚染**が蓄積。閾値で**変異**(利点/欠点が半々) | 刻印《耐毒》、除染 |
| **gravity** 低 | 移動が速い(速度+10)。近接ダメージ減。落下ダメージ無し | ― |
| **gravity** 高 | 近接ダメージ増。積載上限が減る。**速度は下げない** | 体力 |

- **速度補正は 10きざみでしか動かない**([[D-91]])。
  エネルギー表は 109→5 / 110→10 の段差を意図して持っている([[doc:core]] §2.1)が、
  あれは**速度が10きざみでしか変わらない前提**の段差で、
  「減速を食らったら半減」という意味だった。常時かかる重力に細かい補正を許すと、
  -1 のつもりが行動回数半減になる。実際 遺跡(1.1G)が速度109 = 半減で、
  **深度60の関門が深度100より難しい**主因になっていた。

  さらに表には**緩やかな減速帯が無い** ―― 109 で 0.5倍、100 で 0.3倍。
  常時かかる環境が速度を下げると、それは調整つまみではなく壁になる。
  そこで**重力は速度を上げるだけ**にした。高重力は近接ダメージと積載で効く。
  一時的な `slow` は今までどおり段差を踏む ―― そちらは踏ませたい効果。

  | 重力 | 速度 | 該当 |
  |---|---|---|
  | ≤0.8 | **+10** (2.0x) | 方舟 0.3G |
  | 0.8〜1.8 | 0 | 灰 1.0 / 尖塔 1.0 / 遺跡 1.1 / 《起源》 1.4 |
  | ≥1.8 | **-10** (0.3x) | 現状どのサイトも該当しない |
| **surveillance** | 発見されると**増援が湧き続ける** | 隠密、階を移る、《適合:監視》。**監視系の破壊は未実装**(M4) |
| **ambient** 0 | ライトの半径が視界の全て | セル、暗視 |

## 8.4 気密(Seal) ― 中核の新軸

docs/00 §0.4(1) の「気密」をここで確定させる。

```
必要気密 = ceil((60 - 気圧) / 15)      気圧60以上なら 0
不足量   = max(0, 必要気密 - 装備の気密合計)
減圧ダメージ = 不足量 * (2 + 深度/10)  毎ゲームターン
```

| 気圧 | 必要気密 | 状況 |
|---|---|---|
| 60〜100 | 0 | 呼吸できる |
| 45 | 1 | 薄い。作業スーツで足りる |
| 30 | 2 | 苦しい |
| 15 | 3 | 真空作業服が要る |
| 0 | 4 | 完全真空 |

### 気密が「HPとは別の資源」である理由
- **被弾で減る。** スーツの `damaged` が増えると気密も落ちる(M2 で実装済みの損傷を接続)。
- **母船でしか完全には直せない。** 現場修理(能力)は一時的。
- → **「HPは足りているが気密が保たない」という撤退理由**が生まれる。
  Angband の撤退理由は HP と消耗品だけだったが、ここに第3の軸ができる。

### 発声制限
減圧下では **精神系(psi)と生体系(bio)の能力が使えない**(機械系は使える)。
→ サイトによってロールの強弱が変わる。念導者は方舟が苦手。

## 8.5 減圧の伝播 ― 方舟の signature 機構 ([[D-47]])

漂流艦《方舟》だけの機構。**隔壁扉が気圧を区切っている。**

- 各部屋が**個別の気圧**を持つ。通路は低圧。
- **扉を開けると、隣接区画と気圧が均される**(高い方から低い方へ)。
- 高圧区画から低圧区画へ扉を開けると、**突風でアクターが押し流される**。
- 敵は扉を開けない。**プレイヤーだけが気圧を操作できる。**
- 降り立った区画は必ず与圧されている。入った瞬間に窒息させない。

### 破断は深度で進む ([[D-62]])

浅い層はまだ船が生きていて、深部ほど壊れている。
**破断している区画の割合と、破断の深さの両方**が深度で変わる。

| | 最浅部(深度1) | 中間 | 最深部(深度40) |
|---|---|---|---|
| 破断している割合 | 10% | 50%前後 | 85% |
| 破断区画の気圧 | 45 | 28前後 | 10 |
| そこに入るのに要る気密 | 1 | 3 | 4 |

必要気密が段階的に上がることで、
**作業スーツ(深度1)→ 真空作業服(深度4)→ 装甲スーツ(深度10)**
という装備の階段と噛み合う。
一律に真空(必要気密4)にすると、装甲スーツが買える深度10 まで
**一歩も入れない区画**が生まれ、方舟が環境ダメージだけの場所になる。

### これが生む選択
- 安全な高圧区画を通りたいが、扉を開けると自分の背後が減圧する
- 敵の群れを低圧区画に閉じ込める / 突風で吹き飛ばす
- **地形が武器になる**。Angband に無かった軸

## 8.6 昼夜 ― 灰の地表の signature 機構

地表サイトのみ。**1000ゲームターン周期**で昼夜が入れ替わる。

| | 昼 | 夜 |
|---|---|---|
| 環境光 | 2(遠くまで見える) | 0(ライトが全て) |
| 温度 | 高い(+40) | 低い(-40) |
| 放射線 | **高い**(恒星風が直撃) | 低い |
| 敵 | 少ない | **多い。強い個体が出る** |

→ **昼は被曝しながら見通しよく動き、夜は隠れて凌ぐ**。
   時間が資源になる唯一のサイト。

## 8.7 サイト別の環境プロファイル

数値の正本は `src/data/sites.json`。ここは**設計意図**のみ。

| サイト | 気圧 | 温度 | 放射 | 汚染 | 重力 | 監視 | 環境光 | 一言 |
|---|---|---|---|---|---|---|---|---|
| **方舟** | **0〜70(区画ごと)** | 低 | 低 | 中 | **0.3** | 低 | 0〜1 | 気密が全て。低重力で速いが弱い |
| **灰の地表** | 45(薄い) | **±40(昼夜)** | **高** | 低 | 1.0 | 0 | **0 or 2** | 被曝と昼夜。遮蔽物が命 |
| **異星遺跡** | 55 | 高 | 中 | **高** | 1.1 | 0 | **0(完全暗黒)** | 電力が尽きたら終わり |
| **超高層《尖塔》** | 90(正常) | 正常 | 低 | 低 | 1.0 | **高** | 2 | 環境は安全。人と監視が敵 |
| **《起源》** | 変動 | 変動 | **高** | **高** | **変動** | **極** | 変動 | 全部同時。適合が要る |

### 設計の要点
- **尖塔だけ環境が安全**。代わりに監視と人間の敵で圧をかける。
  「環境が全部きつい」だと単調になるので、1つは逆を置く。
- **遺跡の完全暗黒**が、セル経済(docs/00 §0.4-2)が最も効くサイト。
- **方舟の低重力**は唯一「有利になる」環境。移動が速い = 逃げやすい。
  ただし近接ダメージが落ちるので、遠隔と能力の出番になる。

## 8.8 環境の可視化

プレイヤーが環境を**読めなければ設計として機能しない**。

- サイドバーに**危険な環境値だけ**を常時表示(安全な値は出さない)。
- 気密が不足している時は**赤く点滅相当の強調**。
- 入階時のメッセージで環境を一言告げる(「気圧が低い。」「計器が振り切れている。」)。
- `C`(キャラクター画面)に現在階の環境値と自分の耐性を並べて出す。
- 詳細は §[[doc:ui]] §9.5。

## 8.9b 環境ダメージの較正 ([[D-54]])

> **原則: 環境ダメージだけで死なせない。1階層の滞在で HP の 2〜3割を上限にする。**
> 環境は敵と重なったときに殺す。単独では「じわじわ削って撤退を促すもの」に留める。

| 環境 | 較正 | 逃げ道 |
|---|---|---|
| 温度 | 閾値(+55 / -25)を超えた分だけ。**遮蔽物の陰では効かない** | 建物・岩陰に入る / 耐性の刻印 |
| 放射線 | `120/線量` ターンごとに被曝+1。**遮蔽で 1/4** | 陰を伝う / 耐放射 / 除染 |
| 汚染 | `150/汚染度` ターンごとに +1。空気なので遮蔽は効かない | 耐毒 / 除染 / 早く抜ける |
| 重力 | ダメージ無し。速度・近接・積載に効くだけ | ― |
| **減圧** | **例外。明確に致死的** | **完全に予防可能**(気密装備を持つ) |

**減圧だけが例外**なのは、これが「装備が無ければこのサイトには入れない」という
**通行止めの信号**だから。じわじわ削るのではなく、はっきり「無理だ」と伝える必要がある。
そして気密装備さえあれば完全に無効化できるので、理不尽にはならない。

### 検証
`node src/tests/run.js` の「環境ダメージが1階層でHPの2〜3割に収まる」で自動検査する。

## 8.10 この設計が避けていること

- **環境ダメージを「ただの追加ダメージ」にしない。** すべて
  「特定の装備を要求する」形にする。HP を削るだけの環境は作らない。
- **完全に対処不能な環境を作らない。** どの環境も、
  対応する装備か立ち回りが必ず存在する。
- **環境を毎階ランダムにしない。** サイトごとに固定する。
  「このサイトはこういう場所だ」と学習できることが重要。
