# 0. 企画コンセプト

## 0.1 なぜ作るか / 何を作るか

Angband は「単一の深度スケール上に、敵とアイテムの出現テーブルが乗っている」という
極めて強靭な骨格を持つ。40年近く生き延びているのはこの骨格のためで、
**この骨格は世界観から独立している**。本企画はその骨格を丸ごと継承し、
上に載る意味論だけをSFに置き換える。

- **ベースライン**: Angband クローン相当の機構(§docs/02)。ここは創作せず、本家の設計を写す。
- **差分**: 世界観・用語・4サイト構造・環境ハザード・電力経済・電脳層(§0.3〜0.5)。

**やらないこと**: 本家の忠実なファンタジー版を先に作ってから塗り替える、という二度手間はしない。
初日から用語はSF。ただし**内部の数式・テーブル構造は本家準拠**なので、
バランス調整時に本家の値を参照して当てられる。

---

## 0.2 世界観

西暦は既に意味を失っている。人類圏は一度「**大断絶(The Severance)**」で切れた。
何が起きたのかは誰も知らない。ただ、断絶より前に作られたものは、
どれも**同じ設計思想の痕跡**を持っている ―― 異星の遺跡でさえも。

プレイヤーは**サルベージ船《アンカー》**の乗員。
《アンカー》は星系を渡り、断絶前の遺構に降下し、technology を回収して売り、
また潜る。目的は最初は金と装備。だが深く潜るほど、
4つのまったく異なる現場が**同じ一つのものを指している**ことに気づいていく。

深度100、すべての層の底に **《起源》(THE ORIGIN)** がある。

### トーン
- 説明しすぎない。ログ断片・破損データ・遺体の所持品で語る(Angbandの `*_info` 相当)。
- ホラー寄りだが絶望一辺倒にしない。**装備が整うと世界の見え方が変わる**カタルシスを重視。

## 0.3 4サイト統合の設計 ★本企画の要

4つの世界観を「別ゲーム」にしないための仕掛けが **単一深度スケール** である。

> **深度(Depth) 1〜100 は全サイト共通の絶対値。**
> どのサイトの深度30も、敵の強さ・アイテムの質は等価。
> サイトが変えるのは **地形生成器・敵プール・環境ハザード・固有報酬** のみ。

これにより Angband の `alloc_table`(深度別出現確率)を**サイト横断で1本だけ**持てる。
コンテンツを4倍作る必要はなく、「共通プール + サイト固有プール」の2層で足りる。

| サイト | 深度レンジ | 地形 | 固有ハザード | 空気感 |
|---|---|---|---|---|
| **漂流艦《方舟》** Derelict Ark | 1–40 | 直線的な区画・隔壁・通路。Angband古典型ルーム生成が最も素直に効く | **減圧/真空**(気密が要る) | 閉所ホラー。Alien / System Shock |
| **灰の地表** Ashlands | 1–30 | 半開放。廃墟ブロック + 地下シェルター | **放射線**(累積被曝) | ポストアポカリプス。資源の乏しさ |
| **異星遺跡** Xeno Ruins | 10–60 | 自然洞窟 + 非ユークリッド的な異星建築の混成 | **異種生体汚染** | 未知。Metroid的な圧 |
| **超高層《尖塔》** Arcology | 20–80 | 垂直。フロアが狭く縦に長い。**電脳層(Netspace)を併設** | **監視/自律防衛**(発見されると増援) | サイバーパンク。人が居る不気味さ |
| **《起源》** The Origin | 80–100 | 上記4種の地形が混ざり崩れていく | 全部 | 収束。ここで謎が閉じる |

- 序盤(深度1–10)は **漂流艦** と **灰の地表** の2択で始まる。どちらでもよい = リプレイ性。
- 深度80以降は《起源》に一本化。**深度99に門番ユニーク、深度100に《起源》本体**(本家の Sauron/Morgoth 構造を踏襲)。
- サイト間の移動は拠点《アンカー》経由。**到達最深度は記憶される**(本家の「最深到達階から再開」相当)。

### 星系マップ(拠点画面)
本家の「町」を **母船《アンカー》** に置換。ここが唯一の安全地帯。
- **交易区** = 店(§docs/03)
- **格納庫** = ホーム(倉庫)
- **降下ポッド** = ダンジョン入口。サイトと深度を選んで降りる

## 0.4 Angband に足す4つの独自機構

「クローン + 塗り替え」で終わらせないための追加軸。**いずれもコア機構を壊さない差分**として設計する。

### (1) 環境ハザードと気密 ― 耐性軸の再定義
Angband の耐性(火/冷/酸/電/毒)を、SFの環境軸に読み替えたうえで
**「気密(Seal)」という新軸**を足す。

- 気密が不足する区画では**毎ターン継続ダメージ + 一部行動が禁止**(発声を伴う能力など)。
- スーツの気密値は**被弾で減る**。これが「装甲を修理する」という新しい資源ループを生む。
- 結果: 「深く潜れるか」が HP だけでなく**環境適合**で決まる。サイト選択に意味が出る。

### (2) 電力(セル)経済 ― 消耗品の統一
本家の 杖/ロッド/明かり がバラバラに持っていた充填の概念を、
**単一の資源「セル(Cell)」**に統一する。

- ライト、射出器(旧wand)、ツール(旧staff)、一部インプラントがすべてセルを食う。
- **明かりを点けるとセルが減る**。暗闇で進めば節約できるが、視界と命中が落ちる。
- 「あと何ターン光が保つか」が探索のテンポを作る。Angband の松明/ランタン管理の強化版。

### (3) 電脳層(Netspace) ― 同深度の第2レイヤー
**《尖塔》以降**、ジャックイン装備があれば物理面から**同じ深度のネット面**へ切り替えられる。

- ネット面は別マップだが**深度は同じ**(= 敵/アイテムの強さは等価。テーブルを共有できる)。
- ネット面での行動が**物理面に反映**される: 隔壁を開ける / 監視を切る / 自律防衛を掌握する。
- ネット面では HP ではなく**認知(Cognition)**を削られ、0 になると物理面の肉体が昏倒する。
- 純粋な追加要素なので、M4 まで実装を遅らせても土台が壊れない。

### (4) サルベージと加工 ― エゴ品の内製
本家は「エゴ品/固有品は拾うもの」。本作は**拾ったジャンクを母船の工房で解体・移植**できる。

- 不要装備を解体 → **モジュール**(≒ルーン)を得る → 別の装備に移植してエゴ化。
- 「弱いが好きな装備」を育てられる = ビルドの意図性が上がる。
- 供給過多にならないよう、移植には**深度に応じたレアパーツ**を要求する。

## 0.5 Angband から明確に変える点(緩和)

長寿ゲーム特有の理不尽のうち、現代的に緩和するもの。理由も併記する。

| 本家 | 本作 | 理由 |
|---|---|---|
| アイテム鑑定が総当たり(飲んで確かめる) | **ルーン式鑑定**(近代Angband準拠)。属性ごとに「一度知れば以後全装備で既知」 | 学習が蓄積する快感。無意味な試行を減らす |
| 呪い= 装備すると外せない | **汚染ファームウェア**。デメリット付きだが**外せる**。代わりに強力な利点を持つものがある | 罠ではなくトレードオフにする |
| 能力値の永久減少 | 一時低下 + 母船で治療可能 | 取り返しのつかなさを装備損失に集約 |
| ステータス異常の長時間拘束 | 上限ターンを設定 | 「何もできない時間」を短く |
| セーブスカム抑止なし | **パーマデス厳守**。オプションで「人格バックアップ」(1ラン1回の復活)を提供 | 難易度の入口を用意しつつ本流は硬派 |

## 0.6 タイトルについて

- **仮題: STRATA(ストラータ / 層)** ― 4サイトすべてが「層を掘り下げる」体験であること、
  そして深度が唯一の共通尺度であることを指す。
- コードネーム/リポジトリ名は `xangband` のまま維持。
- 代替案: `VOIDBAND` / `DEEPSTACK` / 邦題『深層』。**M3 到達時に確定**すればよい(それまで改名コストは低い)。
