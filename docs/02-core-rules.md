# 2. コア機構(Angband 準拠)

> **この章は「クローン」の定義そのもの。** ここに書かれた機構は本家 Angband の設計を写す。
> 独自解釈で作り替えない。バランス値は本家を初期値として持ち込み、後から調整する。

---

## 2.1 ターン制 ― エネルギースケジューラ

本家準拠のエネルギー方式。「1ターン = 全員1回動く」ではなく、**速度で行動回数が変わる**。

- 各アクターは `energy` を持つ。**ゲームターン**ごとに `energy += gain(speed)`。
- `energy >= 100` になったアクターが行動し、行動コスト(通常 100)を差し引く。
- 速度の内部表現は **110 = 標準**(本家と同じオフセット)。表示は `+0`。
- `gain(speed)` は本家 4.2 の `extract_energy[]` を踏襲する(`src/js/turn.js` の `ENERGY_TABLE`):

  | 速度 | 表示 | gain | 標準比 |
  |---|---|---|---|
  | 110 | +0 | 10 | 1.0x |
  | 120 | +10 | 20 | **2.0x** |
  | 130 | +20 | 30 | **3.0x** |
  | 140 | +30 | 38 | 3.8x |
  | 150 | +40 | 42 | 4.2x |
  | 109 | -1 | 5 | 0.5x |
  | 100 | -10 | 3 | 0.3x |
  | 90以下 | -20以下 | 1〜2 | 0.1〜0.2x |

- **速度 +10 = 行動回数2倍**。この急峻さは維持する。速度が最重要ステータスであること自体が Angband の設計。
- 表は **上下で非対称**。109 と 110 の間に 5 → 10 の段差があり、
  **標準速度をわずかに下回るだけで半減**する。減速の危険さがこの段差から来ている。
- 加速側は +30 以降で頭打ちになる(38, 42, 45…)。速度を積み続けても青天井にはならない。
- 減速側(109以下)の各値は本家表からの再構成。**表はこのまま据え置く**([[D-91]])。
  段差が成立するのは**速度が10きざみでしか変わらない**前提があるからで、
  細かい補正を入れる側(重力など)をきざみに合わせる ―― [[doc:environment]] §8.3。

### 行動コスト
| 行動 | コスト |
|---|---|
| 移動・攻撃・アイテム使用・能力使用 | 100 |
| 通常より速い/遅い一部行動 | 個別に定義(例: 素早い一撃 50) |
| メタ操作(インベントリ閲覧・地図確認・設定) | **0**(ターンを進めない) |

### ターンループ擬似コード
```
while (player.alive) {
  for (a of actors) a.energy += gain(a.speed)
  for (a of actors.filter(e => e.energy >= 100)) {
    if (a.isPlayer) { await input(); }   // 描画して入力待ち
    else            { aiAct(a); }
    a.energy -= actionCost
  }
  gameTurn++
  upkeep()   // 再生・状態異常・ハザード・電力消費・敵の湧き
}
```
- `upkeep()` は**ゲームターン基準**(実時間でもプレイヤーターンでもない)。
  再生やハザードのダメージが速度で有利不利にならないようにする。

## 2.2 視界・照明・センサー

| 要素 | 実装 |
|---|---|
| **視線(LOS)** | 再帰シャドウキャスティング(8オクタント)。対称性を確保する |
| **光源半径** | 装備するライトのランクで 1〜3。セル消費(§docs/00.4(2)) |
| **常時照明区画** | 生成時に「照明あり」フラグの立った部屋は入室時に全体が見える(本家 `CAVE_GLOW` 相当) |
| **記憶(既知グリッド)** | 一度見た地形は記憶して薄色で描画。敵とアイテムは記憶しない(本家準拠) |
| **暗視** | 系統/装備による無光源視界。半径のみで、色情報は落ちる |
| **センサー** | **本作独自**。周囲 N マスの「敵の存在」だけを地形なしで表示。本家の検知系呪文の常設版 |

- 暗闇で行動すると**命中にペナルティ**、遠隔攻撃の射程が縮む。
  → 「セルを節約して暗く進む」が明確なリスク選択になる。

## 2.3 深度スケーリング ― Angband の心臓部

**深度(Depth) 1〜100** が唯一の難易度尺度。すべての生成物が深度を引数に取る。

### 出現テーブル(`alloc_table`)
敵・アイテムはそれぞれ `{ depth, rarity }` を持ち、生成時に深度で重み付き抽選する。

- **通常生成**: 抽選対象は「その深度以下」に出現しうるもの。深度が上がるほど強いものが混ざる。
- **深度外(Out-Of-Depth / OOD)**: 一定確率で `depth + boost` として抽選する。
  → 「浅い階で明らかに格上」が稀に出る。**この事故性が Angband の緊張感の正体**なので必ず残す。

  | 対象 | 発生率 | 押し上げ量 | 本家の対応 |
  |---|---|---|---|
  | 敵 | **1/25** | `+min(depth/4 + 2, 10)` | `ood_monster_chance` / `ood_monster_amount` |
  | アイテム | **1/20** | `1 + depth*100 / rand(1..100)` (100で頭打ち) | `GREAT_OBJ` |

  アイテム側の式は「稀に極端に良いものが出る」形。分母が小さい値を引くと押し上げが跳ねる。

### 抽選の重み
各エントリは `{ depth, rarity }` を持つ。`depth <= 抽選深度` のものだけを対象に、
重み `1/rarity` で選ぶ。`rarity` が大きいほど出にくい(本家 `alloc_entry` と同じ考え方)。
出現しうるものが1つも無い場合は、対象深度を1つずつ下げて再探索する。
- **サイト補正**: `sites.json` の重みで、そのサイトらしい敵/物が出やすくなる。
  ただし**強さの基準は動かさない**(重みの偏りのみ。§docs/01.5-2)。

### 階の予感(Level Feeling)
本家の "level feeling" を **センサー予測**として実装。入階時に2値を表示する。

| 値 | 算出 |
|---|---|
| **危険度 0〜9** | 階の敵の「深度超過量」の合計から。`sum(max(0, 敵depth - 階depth) + 1)` を閾値表で丸める |
| **有望度 0〜9** | 階のアイテムの価値合計から。固有機材・改修品・深度外品が強く効く |

- **有望度は階を歩いて初めて開示**する(本家準拠)。入階直後は危険度だけが分かる。
  → 「危険そうだが中身が分からない」状態から探索が始まる。
- 危険度 0 は「何もいない」を意味する。撤退の判断材料として機能させる。

### 区画テンプレートと封鎖区画(Vault)
- **区画テンプレート**(`rooms.json`) … 医療ベイ / 機関室 / 艦橋 / 格納庫 など、
  形の決まった部屋。文字列マップで定義し、生成時に貼り付ける。
- **封鎖区画 Vault**(`vaults.json`) … 小・大の2段。**敵とアイテムが同時に高密度**で置かれる。
  - 中身は `depth + 10`(小) / `depth + 20`(大) で抽選する。明確に格上が出る。
  - **外から中身が推測できる意匠**にする(入るかどうかがプレイヤーの判断になるため)。
  - 大 Vault が出た階は危険度と有望度が同時に跳ね上がる。

### 階層の永続性
本家準拠で**非永続**。降りるたびに階は生成し直され、戻っても同じ階ではない。
- 例外: 《起源》の一部フロアのみ固定(エンドゲームの構造を作るため)。

---

《起源》の深度98〜100 だけは**マップそのものが固定**される
([[doc:endgame]] §7.4)。手書きのマップは閉じた区画を作りやすいので、
**床が全て昇降機から歩いて行けること**をデータ検証で強制する ([[D-72]])。

## 2.4 ダンジョン生成

古典 Angband の生成器を基本形とし、サイト別に差し替える。

### 共通アルゴリズム(`gen-common.js`)
1. マップを一様の岩/構造材で埋める
2. ブロックグリッドに分割し、各ブロックに部屋を試行配置(重なり判定)
3. 部屋の中心同士をトンネルで接続(曲がり・貫通・ドア生成の確率パラメータあり)
4. 階段・アイテム・敵・トラップ(=**設備障害**)を配置
5. 連結性を検証(到達不能な階段/宝が無いこと)。失敗したら**生成をやり直す**

### 部屋タイプ(本家準拠)
単純矩形 / 重複矩形 / 内室付き / 柱配置 / 円形 / 十字 / 堀(moat) /
**区画テンプレート**(`rooms.json`) / **大型区画 Vault**(`vaults.json`、小・大の2段)

Vault は「高密度の敵と高品質の報酬が同居する閉鎖区画」。本家同様、
**入るかどうかがプレイヤーの判断**になるよう、外から中身が推測できる意匠にする。

### サイト別生成器(`gen-sites.js`)
| サイト | 生成の性格 |
|---|---|
| 漂流艦《方舟》 | 共通アルゴリズムほぼそのまま。**隔壁**で区画が閉じており、開放で減圧が起きる |
| 灰の地表 | 部屋を減らし**外周を開放**。見通しが良く遠距離戦が主体。遮蔽物の配置が鍵 |
| 異星遺跡 | セルオートマトンの洞窟 + 幾何学的な異星構造を**混成**。通路が不規則 |
| 超高層《尖塔》 | マップを縦長にし部屋を小さく。**監視カメラ**が視界を持ち、発見で増援が湧く |
| 電脳層 | 格子状の抽象空間。壁 = ICE(防壁)。地形自体が敵性 |
| 《起源》 | 上記の生成器をフロアごとに切り替え、深度が上がるほど混線・破綻させる |

## 2.5 キャラクター基盤

- **能力値6種**(本家の6軸を維持、名称をSF化)
  | 本作 | 本家 | 主な効果 |
  |---|---|---|
  | 体力 STR | STR | 近接ダメージ・攻撃回数・積載量 |
  | 演算 INT | INT | 電脳/機械系能力の威力・失敗率、鑑定 |
  | 意志 WIS | WIS | 精神系能力・精神耐性・センサー精度 |
  | 反射 DEX | DEX | 命中・回避・攻撃回数・器用さ判定 |
  | 耐久 CON | CON | HP・ハザード耐性 |
  | 統率 CHR | CHR | 取引価格・味方ドローンの制御数 |
- **HP / SP**: HP は耐久とレベル。SP に相当するものはロールごとに名称が変わる
  (念導=**集中**、機械系=**帯域**、生体系=**血中濃度**)。**機構は本家のSPと同一**。
- **能力値の範囲**: 本家と同じ **3〜18 → 18/01〜18/220**(パーセンタイル)を採用する([[D-34]])。
  - **内部表現は単一の整数**。`3〜18` はそのまま、`19` 以降が `18/10`, `18/20`, … を表す
    (内部値 `v > 18` のとき `18/((v-18)*10)`)。上限は内部値 40 = `18/220`。
  - 表示だけが `18/50` の形になる。比較・加算は整数演算で済む。
  - 補正表は **`statIndex(v)`** で圧縮した添字で引く(本家 `stat_ind` と同じ考え方)。
  - **なぜ必要か**: 18 で頭打ちだと、能力値上昇アイテムが深部で即座に無意味になる。
    50レベルぶんの伸びしろを作るのが 18/xx の役割。
- **レベル**: 1〜50。必要経験値は本家の `player_exp[]` を踏襲し、系統/ロールの
  **経験値倍率**(`expFactor`, 百分率)を掛ける。強い組み合わせほど成長が遅い。
- **経験値の獲得**: 本家式 `gain = 敵のmexp * 敵のlevel / プレイヤーのlevel`。
  → 深いところの敵ほど旨みがあり、自分が育つほど雑魚の価値が落ちる。
- **HP**: `hpMax = 系統/ロールのヒットダイス` をレベルぶん累積し、耐久ボーナスを加える。
  同一シード・同一レベルなら必ず同じ HP になるよう、レベルごとのロールを固定シードで引く。

## 2.6 戦闘

本家の計算構造をそのまま持ち込む。

- **命中判定**: 本家 `test_hit()` を踏襲。

  ```
  power = 命中技能 + 命中ボーナス * 3
  1) 5% の確率で「揺らぎ」に入り、そのうち 12% だけ命中する (= 実質 0.6% の下駄)
  2) power <= 0 なら必ず外れる
  3) それ以外は  rand(0..power-1) >= floor(AC * 2 / 3)  で命中
  ```
  → AC は「当たりにくさ」として効く。AC の 2/3 しか見ないので、
    AC を上げ続けても命中率は 0 に漸近するだけで無敵にはならない。

- **攻撃回数(Blows)**: 体力・反射・武器重量から算出する。
  ```
  power = (体力 - 8) + (反射 - 8)
  blows = clamp(1 + floor(power * 8 / (武器重量 + 100)), 1, ロールの上限)
  ```
  → 「軽い武器を速く振る / 重い武器を確実に当てる」の選択が成立する。
  【暫定】本家の `blows_table` は 3次元表で、M5 で照合しながら置き換える。
- **ダメージ**: 武器ダイス + ボーナス。**スレイ/ブランド**(特定系統に倍率、属性を付与)を本家同様に持つ。
  SF読み替え: 対機械弾頭 / 対生体毒素 / 徹甲 / 高熱 / 極低温 / 電磁 / 腐食。
  倍率は**ダイスにだけ**掛かり、固定ボーナスには乗らない(本家準拠)。
  スレイとブランドは重ならず、**最大のもの1つだけ**が効く。
- **《異常》にはスレイが効かない** ([[D-92]])。
  スレイは「相手が何であるか」に賭ける刻印だが、`aberrant` は**分類できないもの**
  ([[doc:content]] §3.4)。分類に基づく倍率が当たらないのは設定どおりの帰結。
  代わりに**ブランド(属性)は効く** ―― 属性は分類ではなく現象だから。
  ただし `aberrant` は電磁・毒素・放射に耐性を持つので、通るのは高熱・極低温・腐食。
  → 終盤が「正しいスレイを引いたか」の抽選でなくなり、
    **属性の噛み合わせと素の火力**で解く戦いになる。
- **クリティカル**: 本家式の追加ダイス。
- **遠隔**: 射出器(旧・弓)+ 弾体。本家の**倍率構造**を維持する。

  ```
  ダメージ = (弾体ダイス + 弾体toDam + 射出器toDam) * 射出器の倍率
  命中     = 射出技能 + (弾体toHit + 射出器toHit) * 3 + レベル*3
  射程     = 10 * 倍率  (上限 20)
  ```
  → **倍率は最後に掛かる**ので、射出器の質がダメージを支配する。
    本家同様「良い射出器を手に入れた瞬間に戦い方が変わる」性質を保つ。
  - 弾体は撃つと **1/4 の確率で壊れる**(回収して撃ち直せる)。
  - 遠隔攻撃は 1ターンに1発。攻撃回数(blows)の対象外。
- **敵の攻撃**: `{ 手段, 効果, ダイス }` の組(本家の blow method/effect)。
  効果には HP 減以外に「装備損傷」「能力値低下」「セル吸収」「気密破壊」を含む。

## 2.7 状態異常・ハザード

本家の状態異常を維持しつつ、**上限ターンを設定**して理不尽さを緩和(§docs/00.5)。

- **持続は「そのアクター自身の手番」で数える** ([[D-93]])。
  本家の `process_player` / `process_monsters` と同じ ―― 自分の番が来るたびに1減る。
  ゲームターンで数えてはいけない。速度110のプレイヤーの1手番は**10ゲームターン**なので、
  ゲームターンで数えると**書いた数字の10分の1しか続かない**。
  実測で `paralyzed 16` が**プレイヤー1手番未満**になっていて、
  「相手を止めるための道具」(無効化/停止プロトコル)が構造上止められなかった。
- **麻痺中はプレイヤーも行動できない。** 手番だけが過ぎる。
  対抗手段は《自由行動》の刻印 ―― これが無いと深部の麻痺は致命的になる(本家と同じ)。
- **行動を奪う状態異常には抵抗判定がある** ([[D-94]])。
  対象は 麻痺・混乱・恐慌・盲目・減速 の5つ。毒は判定しない(継続ダメージは通る)。

  ```
  成功率 = clamp(90 - max(0, 相手のレベル - 自分のレベル) * 1.5, 5, 90)   [%]
  ユニークは更に半分
  ```
  → **深いユニークほど固定できない**。本家と同じく、ユニークは状態異常に強い。
    判定を入れないと「麻痺させて殴るだけ」が最適解になり、
    実測で終盤の関門が**最も易しく**なっていた。
    完全耐性にしないのは、それでは道具が死んで「転移で逃げる相手を捕まえられない」
    問題(`[[Q-24]]`)に戻るため。
- **《係留》は行動を奪わない。逃げ道だけを塞ぐ** ([[D-95]])。
  `bind` は転移(`blink`)を打ち消すだけで、相手は全力で戦い続ける。
  **抵抗判定を通さない**(必ず効く) ―― 行動を奪わないので、
  確実に効いても「固定して殴るだけ」にはならない。
  転移する敵は89体中12体(深度17〜96)に分布していて、一部のボス専用の対策ではない。

  | | 行動 | 転移 | 抵抗判定 |
  |---|---|---|---|
  | `afflict:paralyzed` | **奪う** | 止まる | **ある** ([[D-94]]) |
  | `bind` | 奪わない | **止まる** | 無い |

  → 「捕まえられない」への答えは**相手を止めること**ではなく
    **逃げ道を塞ぐこと**。止める道具で代用すると、必ず強すぎるか弱すぎるかになる。

| 状態 | 効果 |
|---|---|
| 出血/毒 | 継続ダメージ |
| 混乱 | 移動/攻撃方向がランダム化。能力使用不可 |
| 恐慌 | 近接攻撃不可 |
| 麻痺 | 行動不能(**上限あり**。連続麻痺を防ぐ耐性を序盤で入手可能に) |
| 盲目 | 視界喪失。読み取り系不可 |
| 幻覚 | 表示が偽装される |
| 減圧 | 気密不足時に継続ダメージ + 発声系不可 |
| 被曝 | 累積値。閾値超過で能力値一時低下。母船で除染 |
| 汚染 | 蓄積で変異(利点/欠点の両方があるランダム変化) |

## 2.8 アイテム機構

### 鑑定 ― ルーン式(**刻印**)
装備の性質は **刻印(sigil)** という単位に分解される。**刻印を1つ知ると、
以後すべての装備でその刻印が既知**になる(本家の近代的なルーンID)。

| 判明の経路 | 内容 |
|---|---|
| **装備する** | 常時発動の刻印(AC・気密・速度・能力値)は装備した瞬間に分かる |
| **発動する** | 条件付きの刻印(特定系統への倍率など)は、その条件を満たしたときに分かる |
| **被弾する** | 耐性の刻印は、その属性で殴られたときに分かる |
| **解析する** | 母船の情報屋で費用を払えば即座に分かる |

- 装備の名前は「既知の刻印だけ」で組み立てる。未知の刻印があるうちは
  **「未解析の〜」**と表示され、全て既知になると正式名になる。
- 消費アイテム(アンプル/プロトコル)は刻印ではなく**フレーバー式**:
  一度使えばその種別が既知になる。
- **フレーバー**: 未鑑定時の見た目は**毎ラン シャッフル**(`flavors.json`)。
  「濁ったアンプル」が何かはランごとに変わる。本家の核心的な楽しさなので維持。

### 改修品(エゴ)・固有機材・汚染ファーム
| 種別 | 生成 | 個数 |
|---|---|---|
| **改修品** | ベース品 + 刻印セット。深度で出現率と質が上がる | 何個でも |
| **固有機材** | 個別定義。深度と稀少度で管理 | **1ランに1個**(倒されても再生成しない) |
| **汚染ファーム** | 負の刻印。**強力な利点と同居**する形でのみ生成する | 何個でも |

- 生成時に確率で「良い品」判定が入り、通ると改修品、さらに通ると固有機材を試みる(本家の構造)。
- **汚染ファームは外せる**([[D-07]])。装備を外す = 利点も失う、というトレードオフにする。
- **スタック**: 同一種別・同一状態のものだけ重なる(本家準拠)。
- **重量と積載**: 体力で上限。超過で速度低下(本家準拠)。**取捨選択を強いる**ので必ず入れる。
- **店**: 母船《アンカー》の交易区。在庫は定期的に入れ替わり、深度到達で品揃えが伸びる。

## 2.9 敵AI

本家の水準(素朴だが十分機能する)を目標にする。過剰に賢くしない。

0. **睡眠と覚醒**([[D-40]]): 敵は **眠った状態で配置される**。これが無いと、
   経路探索を持った全ての敵が初手からプレイヤーへ殺到し、階に入った瞬間に詰む。
   ```
   配置時   asleep = rand(sleep .. sleep*2)     sleep は敵ごとの警戒度(小さいほど起きやすい)
   毎ターン asleep -= 騒音 / (1 + 距離)
            騒音 = max(1, 30 - 隠密技能)        視界内なら 2倍
   asleep <= 0 で覚醒。一度起きた敵は二度と眠らない。
   ```
   → **隠密技能がここで初めて意味を持つ**。忍び寄って各個撃破するか、
     騒がしく突っ込んで群れを起こすかがプレイヤーの選択になる。
   → 眠っている敵への攻撃は必ず命中し、不意打ちの倍率が乗る。

1. **知覚**: 視線(LOS)で直接見るか、**音のマップ(flow)**で追う([[D-35]])。
   - プレイヤーを起点に BFS で「距離マップ」を作り、敵は値の小さい方へ進む。
   - 壁を回り込めるので、通路や角で待ち伏せる挙動が自然に出る。
   - flow はプレイヤーが動いた階でのみ再計算する(1階 6000マス程度なので毎ターンでも軽い)。
   - 一定距離を超えると届かない = 遠くの敵は寄ってこない。
2. **接近**: 経路を辿る。通路で待ち伏せる挙動を持つ個体もある
3. **遠隔**: 射線が通れば確率で遠隔攻撃/能力使用(§2.9.1)
4. **逃走**: HP が閾値未満、または恐慌で逃げる。**逃げた敵は仲間を呼ぶことがある**
5. **群れ**: 一部の敵は護衛(escort)を伴って生成される
6. **ユニーク**: 固有名を持ち、1ランに1体。倒すと二度と出ない。深度の節目に配置

### 2.9.1 敵の遠隔攻撃 ([[D-68]])

本家の `spell_freq`(1_IN_X)をそのまま踏襲する。
**近接しかない敵しか居ないと、深部が「殴り合いの数字比べ」に収束する。**
プレイヤー側には既に射出器と能力があるので、敵側にも同じ軸を返す。

```
spells: { freq: 5, list: ["bolt:rad:4d6", "breach", "summon:2"] }

freq … 視線が通っている間、毎手番 1/freq で発動する
       近接可能な位置でも撃つ。ただし発動した手番は移動も殴打もしない
list … 発動時に等確率で1つ選ぶ
```

| 種別 | 書式 | 効果 |
|---|---|---|
| `bolt` | `bolt:<属性>:<nDs>` | 射線上の単体へダメージ。耐性と刻印が効く |
| `breath` | `breath:<属性>:<割合>` | 自分の現HPの割合ダメージ。**扇状に届く**。本家のブレスと同じ |
| `status` | `status:<状態>` | 混乱・盲目・恐慌・麻痺など。[[doc:core]] §2.7 の状態を使う |
| `summon` | `summon:<体数>` | 同深度の敵を呼ぶ。呼ばれた敵は起きている。**呼ばれた敵自身は呼べない**([[D-90]]) |
| `heal` | `heal:<割合>` | 自分を回復。HP割合 |
| `blink` | `blink:<距離>` | 短距離転移。射線を切られたときの立て直し |

- **環境属性 `vacuum` `rad` `taint` `watch` は《適合》で無効になる**([[doc:endgame]] §7.2)。
  これが《門番》(深度99)の設計の土台になる。`watch` はダメージではなく増援を呼ぶ。
- **召喚は一世代で止まる**([[D-90]])。呼ばれた敵は召喚呪文を選べない。
  止めないと連鎖する ―― 召喚する敵は全体の22%あり、うち3体は**呪文が召喚しかない**。
  実測で《培養者》戦の盤面が **20手で 2体 → 43体**になり、
  **深度60の関門が深度100より難しい**という順序の逆転を生んでいた。
  併せて1階のアクター数に**上限60**を置く(通常階の人口の実測上限)。
- 遠隔を持つ敵は **`sleep` を大きめ**にする。起きた瞬間に射線が通っていると、
  近づく前に削られて「何が起きたか分からないまま死ぬ」ため。
- 敵の遠隔は**敵の知識(§2.11)に記録される**。一度見た攻撃は次から予期できる。

## 2.10 能力(サブシステム)

本家の呪文機構をそのまま踏襲する。名称だけがロールごとに変わる(docs/03 §3.3)。

- **3系統**: 精神系(集中) / 機械系(帯域) / 生体系(血中濃度)。ロールが1つ持つ(持たないロールもある)。
- **習得**: レベルが上がると習得可能数が増える。習得は不可逆(本家準拠)。
- **コスト(SP)**: 能力ごとに固定。SP が足りなければ使えない。
- **失敗率**: 本家式。
  ```
  fail = 基礎失敗率 - 3*(レベル - 必要レベル) - 主能力値による補正
  SP が足りない場合は +25
  最低 5% / 最大 95% で丸める
  ```
  → **主能力値を上げると失敗率が下がる**という本家の関係を保つ。
- **SP の上限**: 主能力値とレベルから算出。主能力値が低いと 0 になり、能力を一切使えない。

## 2.11 敵の知識(monster memory)

倒すほど、殴られるほど、その敵について分かることが増える(本家 `lore`)。

| 分かること | 条件 |
|---|---|
| 見た目・名前 | 一度見る |
| 攻撃手段と効果 | その攻撃を受ける |
| おおよその HP | 一定回数倒す |
| ドロップ傾向 | ドロップを見る |
| 耐性・弱点 | その属性で攻撃する |

- 知識は**ランを跨がない**(パーマデスなので毎回ゼロから)。
- 【暫定】ラン跨ぎで残す「図鑑」を用意するかは M5 で判断する。
