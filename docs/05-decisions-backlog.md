# 5. 決定事項ログとバックログ

## 5.1 決定事項(なぜそうしたか)

| # | 決定 | 理由 |
|---|---|---|
| D-01 | バニラJS + ブラウザ + 単一HTML | 環境に Node/Python しか無い。card-eleven で確立済みの流儀を再利用でき、立ち上がりが最速。配布もファイル1枚 |
| D-02 | 忠実なファンタジー版を作らず、初日からSF語 | 二度手間のリスキンを避ける。**内部の数式は本家準拠**なので、バランスは本家の値を参照して当てられる |
| D-03 | 深度を全サイト共通の絶対値にする | 4世界観の統合コスト(出現テーブル4本)を消す。コンテンツは「共通 + サイト固有」の2層で足りる |
| D-04 | 速度 +10 = 行動2倍 という本家の急峻さを維持 | 速度が最重要ステータスであること自体が Angband の設計。緩和すると別物になる |
| D-05 | 階層は非永続(《起源》のみ例外) | 戻って稼ぐループを封じる。前進の圧を保つ |
| D-06 | 鑑定はルーン式(近代Angband準拠) | 総当たり試飲は「学習」ではなく作業。刻印の知識が蓄積する形にする |
| D-07 | 呪いを「外せる汚染ファーム」に変更 | 罠ではなくトレードオフに。プレイヤーの選択にする |
| D-08 | 能力値の永久減少を廃止 | 取り返しのつかなさは**装備損失**に集約する。二重に厳しくしない |
| D-09 | パーマデス厳守。人格バックアップは任意オプション | 本流は硬派に保ちつつ、入口を用意する |
| D-10 | ルール層を DOM 非依存に強制 | ヘッドレスな自動プレイ・統計テストの前提。バランス調整の生命線 |
| D-11 | `Math.random()` を全面禁止 | 決定論再現がバグ再現とテストの土台。1箇所の違反で全部崩れる |
| D-12 | 電脳層を M4 に後置 | 純粋な追加レイヤーとして設計し、遅らせても土台が壊れない構造にした |
| D-13 | 敵AIは本家水準に留める | 過剰に賢いAIは Angband の「物量と事故」の面白さを壊す。賢さより**数と多様性** |
| D-14 | データを JSON に外出し | バランス調整をコード変更なしで回す。参照表を自動生成して SPEC との同期ズレを防ぐ |
| D-15 | 企画書を**三層の正本**(設計意図=docs / 数値=data / 一覧=生成物)で運用する | 手書き転記は必ず腐る。一覧を data から生成すれば同期ズレが原理的に起きない ([[doc:docrules]] §6.1) |
| D-16 | 更新規約を `CLAUDE.md` に置く | 規約を docs の奥に書いても読まれない。セッション開始時に自動で読まれる場所に置いて初めて実効性が出る |
| D-17 | 相互参照を `[[ns:id]]` 記法にし、**ID は追記のみ**(改名・再利用・削除の禁止) | 後から wiki 化する際、ID がそのまま permalink になる。一度でも再利用すると外部リンクが壊れる ([[doc:docrules]] §6.5-6.6) |
| D-18 | 更新規約を**機械検査**する `tools/check_docs.js` を最初に作る | 「守ろう」だけの規約は守られない。C-1〜C-10 を CI 相当で落とすことで初めて維持される |
| D-19 | スポイラーを **3段階**(基本/標準/完全)で出し分ける | 一括公開すると未プレイの人が読めない。data の各フィールドに `spoiler:` を持たせれば生成時のフィルタで済む |
| D-20 | `docs/reference/` はコミットし、`dist/` はコミットしない | 参照表は GitHub 上で diff レビューしたい。スポイラー/wiki 成果物は再生成可能なので不要 |
| D-21 | 端末(80x40固定)とマップ(論理120x50・可変)を**最初から分離**し、ビューポートで追従スクロールする | 後付けでスクロールを入れると描画・入力・FOV の座標系を全て触ることになる。M0 のうちに払っておく (Q-02 の解) |
| D-22 | 描画は `{ch,fg,bg}` の**グリフ中間表現**を経由し、ASCII 描画器とタイル描画器を差し替え可能にする | タイル対応を後から入れられる。かつグリフバッファまでは DOM 非依存なので**画面のスナップショットテスト**が書ける (Q-03 の解) |
| D-23 | JS の**結合順と層(rule/shell)の正本を `index.dev.html` に一本化**する | build.py / テスト / lint が同じリストを三重に持つと必ずズレる。card-eleven で重複していた箇所を最初から解消する |
| D-24 | 色は16色パレットを**色名で参照**し、コードに生の `#rrggbb` を書かない | 色覚配慮パレットへの差し替えを1箇所で行えるようにする |
| D-25 | `src/data/*.json` を `build.py` が `src/js/data-gen.js` に変換して埋め込む | 単一HTML・外部依存ゼロなので `fetch` が使えない(file:// で動かない)。正本は JSON のまま保ち、参照表/スポイラー生成器がそのまま読める形を維持する ([[D-15]]) |
| D-26 | 移動キーは **vi風 / テンキー / 矢印 の3流儀を同時受付**する。設定UIは M5 | どれか1つに決める理由が無い。同時受付なら誰も困らず、キーの衝突も起きていない (Q-04 の解) |
| D-27 | 能力値は **3〜18** で始め、本家の `18/xx` パーセンタイルは M2 で導入する | 18/xx は本家の重要な質感だが、M1 の目的(遊べる最小形)には不要。式の形は保つので後から差し込める |
| D-28 | ゲーム進行(`turn.js` `cmd.js`)を **rule 層**に置き、DOM から完全に切り離す | M1 の受け入れ基準「1000回の自動プレイでクラッシュ0」は、ヘッドレスでゲームを最後まで駆動できて初めて測れる |
| D-29 | 敵の視界は**プレイヤーと同じ FOV 関数**を使う | 「敵からは壁越しに見えている」という理不尽を作らない。docs/01 の不変条件5(同じ基盤で動かす)の具体化 |
| D-30 | `Turn.tick` の戻り値を **STOP / SKIP / ACTED** に明示し、**エネルギーを引くのは tick だけ**にする | 呼び出し側と tick の二重消費でターンが永久に進まなくなった。「誰が引くか」を型で表さないと必ず再発する |
| D-31 | **死は一方通行**。`Actor.heal` は死者に効かず、死亡判定は `dead` フラグも見る | 死亡直後の自然回復で HP が戻り、`dead` が立ったままのゾンビ状態が生まれた。スケジューラが死者を飛ばすためターンが止まる |
| D-32 | モンキーテストに **BFS 経路探索と交戦バイアス**を入れる(テスト専用) | 完全ランダムでは壁に張り付き、戦闘・降下・深部のコードが一度も叩かれない。「落ちないが何も検査していない」テストになる |
| D-33 | レベル1の HP は本家同様「系統 + ロール」のヒットダイス**合算**(19)にする | 9 では深度1の敵3発で死ぬ。合わせたところ自動プレイの到達深度が 2.7 → 5.1 に改善した |
| D-34 | 能力値に本家の **18/xx パーセンタイル**を導入する(内部は単一整数、上限 18/220) | 18 で頭打ちだと能力値上昇アイテムが深部で無意味になる。50レベルぶんの伸びしろを作るのが 18/xx の役割 (Q-12 の解) |
| D-35 | 敵の経路探索は本家式の **音のマップ(flow)**。プレイヤー起点の BFS 距離マップを敵が下る | 直進だと角で詰まる。A* は敵ごとに計算が要る。flow なら1階1回の BFS で全敵が賢く動き、待ち伏せも自然に出る (Q-13 の解) |
| D-36 | `glossary.json` は **用語 + 固有名詞**まで。世界観のログ断片は別ファイル `lore.json` に分ける | 用語辞書は wiki の1ページ=1用語に対応させたい。可変長の読み物を混ぜると粒度が壊れる (Q-11 の解) |
| D-37 | 系統/ロール/能力/エゴ/固有機材を **`src/data/*.json` に移し、docs からは表を消す** | 自分で定めた §6.1(数値の一覧を docs に手書きしない)を M2 で実際に適用する。参照表は生成する |
| D-38 | 固有機材は**1ランに1個**。生成済みフラグをランの状態として持つ | 本家の核。同じ固有品が2つ出るとアイテムの意味が崩れる |
| D-39 | 母船《アンカー》を **深度0** として同じ階層構造で表現する | 町を特別扱いすると移動・描画・セーブに分岐が増える。深度0の固定マップにすれば既存の仕組みがそのまま使える |
| D-44 | 深度80以降で**4環境が同時発生**し、各サイト最深部の《適合》がそれぞれ1つを無効化する。4つ揃わないと深度80より下に留まれない | 4サイトあるのに1サイトだけ潜って勝てるなら、他は飾りになる。鍵集めのお使いにせず、**既にある環境という軸を勝利条件に接続**した。ハードゲートは深度80の1箇所だけで、79までは完全に自由 ([[doc:endgame]] §7.2) |
| D-45 | 物語は**ログ断片のみ**で開示する。強制イベント・カットシーンを作らない | 手を止めさせない。全部集めなくても勝てるが、集めた者だけが意味を知る形にする。用語辞書とは粒度が違うので `lore.json` に分ける ([[D-36]]) |
| D-46 | 階層は**7つの環境値**(気圧/温度/放射/汚染/重力/監視/環境光)を持ち、サイト定義から決まる | `seal` と `exposure` が M2 時点で「値はあるが誰も要求しない」状態だった。環境を敵と同格の脅威にするには、**装備の選択を強制する**形が要る ([[doc:environment]] §8.3) |
| D-47 | 漂流艦《方舟》のみ**部屋ごとに気圧を持ち、扉の開閉で伝播**する | 地形を武器にできる軸は Angband に無い。敵は扉を開けないので、**プレイヤーだけが気圧を操作できる**非対称性が選択を生む |
| D-48 | 端末 80x40 は維持し、内訳を変える(メッセージ2行 / サイドバー16桁 / マップ64x38) | 全角ラベルが2桁を食うため 13桁では環境値を足す余地が無い。端末サイズ自体を変えるとテストと描画が全部動く |
| D-49 | **注視/目標指定モード `x`** を新設し、遠隔・能力の目標を記憶する | M2 最大の穴。遠隔と能力を実装したのに「どれを狙うか」がプレイヤーの手に無く、群れの中の1体を狙う選択が成立していなかった |
| D-50 | **オートエクスプロアは入れない。** 代わりに休息 `R` と連続移動 `Shift+方向` を入れる | 電力と食料の消費を「歩いた距離」で払わせる設計なので、自動探索はその経済を丸ごと無意味にする (Q-05 の解) |
| D-51 | 一覧の内容は **`UI.listFor(W, mode)` に一本化**し、描画と選択が同じものを見る | M2 で ui.js(描画) と boot.js(選択) が同じ filter を二重に持ち、順序がズレうる状態だった。構造で消す |
| D-52 | **色の意味を固定**する。アイテムの色=品質、敵の色=系統。この2つを混ぜない | M2 まで場当たりだった。色だけに情報を載せず、数値でも分かるようにする(色覚配慮の前提) |
| D-55 | 操作ヘルプと凡例は **Canvas 疑似端末の外に DOM で置く** | 端末 80x40 は既にサイドバー16桁を使っており、これ以上削るとマップが狭くなる。DOM ならクリック・文字選択・スクロール・折りたたみが無料で手に入り、**端末の設計を汚さない** ([[doc:ui]] §9.11) |
| D-56 | 凡例HUD は**今画面にあるものだけ**を出す。全一覧は出さない | 初心者が知りたいのは目の前の `d` が何かであって、全24種の敵ではない。状況に応じたヒントを最上部に置けば、**チュートリアルを書かずに操作を教えられる** |
| D-98 | **マップのタップでモードに入れない。**未探索・壁をタップしたら「その方向へ1歩」。注視モードは `x` か操作パネルからだけ入る。注視中は同じマスの再タップで決定 | `[[D-97]]` を入れて実機で触ったら、**マップに出た瞬間に操作できなくなった**。未探索マスをタップすると注視モードに入り、注視中のタップはカーソルを動かすだけなので、**閉じる手段が `ESC` キーしか無く指だけでは二度と出られない**。しかも `drawLook` は `panel()` を呼ばないので枠が記録されず、`[[D-97]]` の「枠の外をタップで閉じる」も効かない。新しい階は画面のほとんどが未探索なので、**最初の一タップでほぼ確実にこの罠に落ちる**。原因は「タップの落ち先がモードだった」こと ―― 指で遊ぶときに、抜ける手段の無いモードに落とすのがいちばん困る。1歩進むのは移動と同じコストを払う通常行動なので、`[[D-50]]` が却下したオートエクスプロアには当たらない(行き先はプレイヤーが指している ―― `[[D-86]]` と同じ理屈)。**入れるモードには必ず指で出る道を用意する** |
| D-97 | **キャンバス上の一覧をタップで選べるようにする。**行の当たり判定は描画時に記録し、選択は `handleSelect()` に集約する。枠の外をタップしたら閉じる | `clickMap` に `if (UI.isOpen()) return;` があり、**オーバーレイが開いている間タップが完全に無視されていた**。オーバーレイ25画面のうち**20が「選ぶ」画面**で、所持品・使う・装備・店・能力・降下先・解体/移植・電脳層が全て触れない。決定的なのは**起動直後のモードが `lineage`(系統選択)**だったこと ―― つまり携帯では**ゲームを開始することすらできなかった**。`[[D-86]]`(タップ移動) と `[[D-87]]`(縦積み) で携帯対応したつもりでいたが、**「開く」だけ直して「選ぶ」を直していなかった**。バーチャルDパッドや仮想キーボードは作らない ―― タップ移動が既にあるので二重になるし、`[[D-85]]` で「コマンドを覚えるのが最大の課題」と整理した直後にジェスチャという別の暗記を足すのは筋が悪い。当たり判定を**描いたときに記録する**のは、描画順と選択順がズレないようにするため(`[[D-51]]` と同じ理由) |
| D-96 | **GPL v2 で公開する**。Angband からの由来は `NOTICE.md` に一覧で残す | 機構やルールは著作物ではないので、Angband の設計を継承していること自体はライセンスを縛らない。だが**数値表は表現**で、実際に写している ―― `player_exp[]`(50要素とも同一) / `adj_str_td` / `adj_dex_th` / `adj_con_mhp` / `extract_energy[]` の再構成。**写した以上は継承する**のが筋であり、単一HTMLの無料ゲームにとって GPL v2 の実害はほぼ無い。表を独自の値に差し替えれば MIT にもできたが、成長曲線と命中・ダメージ補正が全部変わるので `[[D-89]]` の関門実測をやり直すことになり、得るものに対して代償が大きい。**由来を曖昧にしたまま寛容なライセンスを主張しない** ―― どこから来たかを書けることのほうが、ライセンスの緩さより価値がある。第三者のコード・アセットは1つも無い(外部依存ゼロ、同梱フォント無し)ので、論点は Angband だけに集約される |
| D-95 | **《係留》(`bind`) を追加する** ―― 転移だけを打ち消し、行動は奪わない。抵抗判定は通さない(必ず効く) | `[[Q-24]]`(《管理人》を捕まえられない)を麻痺で解こうとしたのが間違いだった。麻痺は**行動を丸ごと奪う**ので、効けば強すぎ(`[[Q-25]]` ―― 終盤が最も易しくなった)、抵抗判定を入れて弱めると今度は捕まえられない(実測で成功率18%、時間切れ70%に逆戻り)。**強すぎるか弱すぎるかしか無い**のは、道具が問題に合っていないから。「捕まえられない」の答えは**逃げ道を塞ぐこと**であって**相手を止めること**ではない。`bind` は相手を全力で戦わせたまま転移だけを消すので、確実に効いても戦闘が消えない。転移する敵は89体中12体(深度17〜96)に分布していて、ボス1体のための特例にもならない |

## 5.3 バランスの実測 (M5 時点)

`node src/tests/autoplay.js --runs 192 --by-combo` の結果。
**組み合わせ(8x8=64)は1件あたりのラン数が少なく揺れる**ので、
ロール別・系統別に畳んで見る。

| | 最下位 | 最上位 | 開き |
|---|---|---|---|
| **系統** | 虚空生まれ 3.3 | 合成体 5.1 | **1.6倍** |
| **ロール** | 接続者 2.9 | 狙撃手 5.7 | **1.9倍** |

ロールの順序は
接続者 < 念導者 < 異種生物学者 < 回収屋 ≈ 潜行者 < 工作員 < 突撃兵 < 狙撃手。

### この数字で言えること / 言えないこと

**言える**: 系統の 1.6倍 は許容範囲。抜け穴も無い
(射出は弾を正しく消費しており、狙撃手が強いのは「殴られずに戦える」ため ―― 本家と同じ性質)。

**言えない**: **これは深度4 までの話**でしかない。
自動プレイヤーは平均深度4.2 で死ぬので、測っているのは序盤だけ。
脆い専門職が序盤に弱いのは Angband の設計そのもので、
**中盤以降に追いつくかどうかは、この測定器では判定できない**。

そのため M5 では**曲線を均さなかった**。
測定が支持しない調整をすると、根拠の無い数字いじりになる。

### 測定器の側で直したこと

- **能力を習得しないまま測っていた。** 習得判定が 1/40 だったので、
  レベル6 で4つ覚えられるロールが1つしか持っていなかった。即座に覚えるようにした
- **端末に接続しなかった。** 接続者の identity を使わずに測ると
  「HP の低い突撃兵」を測ることになる。接続するようにした

それでも 1.9倍 は動かなかった。**この差は測定器の怠慢ではなく構造**だと分かった
―― ただし序盤の構造であって、それが正しいかはまだ別の手段が要る (`[[Q-20]]`)。

7. **モバイル対応**: タッチ操作(方向パッド + コンテキストメニュー)
