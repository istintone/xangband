# 10. 細部デザインの差別化設計

> **「Angband の SF リスキン」で終わらせないための設計。**
> M2 でベースラインが完成した今、**何を足すか**より
> **何が違うのか**を先に言語化する。曖昧なまま M3 に入ると、
> サイトが「見た目違いの同じダンジョン」になる。

---

## 10.1 判定基準

差別化できているかどうかを、以下の一文で判定する。

> **同じ深度・同じレベル・同じ所持品で、サイトが変わったら
> プレイヤーの「次の一手」が変わるか?**

変わらないなら、そのサイトは飾りである。以下の設計はすべてこの基準に従う。

---

## 10.2 サイト別の「次の一手」

| サイト | 一手を決めるもの | 具体的に変わること |
|---|---|---|
| **漂流艦《方舟》** | **扉を開けるか** | 気圧が均される。背後が減圧する。突風で敵を飛ばせる。低重力で逃げやすいが近接が弱い → **遠隔と能力が主役** |
| **灰の地表** | **今が昼か夜か** | 昼=見通し良好だが被曝、夜=暗いが敵が強い。**遮蔽物の陰**が被曝を止める → **地形の裏を伝って進む** |
| **異星遺跡** | **電力を何に使うか** | 完全暗黒。ライトを消せば節約できるが視界0。射出器もセルを食う → **光と火力の奪い合い** |
| **超高層《尖塔》** | **見つかっていないか** | 環境は安全。監視に補足されると増援が湧き続ける → **隠密と速度で通り抜ける** |
| **《起源》** | **どの適合を持っているか** | 4環境が同時。持っていない環境が即死要因 → **準備の完了度がそのまま可否** |

### 検証: 同じ状況での分岐
> 深度30・レベル20・HP半分・電力少・回復薬1本

- **方舟**: 扉を閉めて低圧区画に敵を閉じ込め、通路で休息する
- **灰**: 夜が明けるまで岩陰で待つ(被曝しない時間帯を選ぶ)
- **遺跡**: ライトを消して壁を伝い、階段まで暗闇を移動する
- **尖塔**: 監視の死角を数えながら進む。戦闘は絶対に避ける

**同じ入力に対して4通りの正解がある。** これが達成できていれば差別化は成立している。

---

## 10.3 Angband と決定的に違う4点

docs/00 §0.4 で宣言した4機構を、**プレイ体験としての差**に翻訳する。

### (1) 環境が敵と同格 ― 「HPは足りているのに撤退する」
Angband の撤退理由は HP と消耗品しかない。本作は**第3の軸**を足す。

> 気密が保たない / 電力が尽きる / 被曝が閾値に近い

いずれも HP とは独立に「これ以上は進めない」を作る。
**そして母船に戻る理由になる。** 本家の帰還は買い物のためだが、
本作は**修理と除染**のために戻る。

### (2) 電力(セル)が第二の HP ― 「暗闇で節約する」
ライト・射出器・一部インプラントが同じ資源を食う。

> 明かりを消せば節約できる。だが視界が消え、命中が落ちる。

**遺跡ではこれが最も鋭くなる**(環境光0)。
Angband の松明管理を「常時の選択」に引き上げる。

### (3) 刻印による知識の蓄積 ― 「二周目が速い」
刻印は1つ知れば以後すべての装備で既知になる([[D-06]])。

> ランを重ねるほど**プレイヤー自身**が速くなる。キャラクターではなく。

Angband の flavor 学習をランごとにリセットしつつ、
**ラン内での学習曲線**を明確にする。深度20 で「これは加速だ」と即断できる快感。

### (4) サイト選択が戦略 ― 「どこから潜るか」
到達最深度は共通([[D-03]])だが、サイトごとに必要な装備が違う。

> 気密装備が揃ったら方舟。暗視が手に入ったら遺跡。

**装備の入手が、次に行ける場所を開く。** メトロイド的な進行を
ハードゲート無しで(装備の有無という自然な形で)作る。

## 10.4 細部の質感 ― 「SF らしさ」をどこに置くか

見た目を SF にしただけでは質感は出ない。**振る舞いに置く。**

| 要素 | ファンタジーなら | 本作 |
|---|---|---|
| 回復 | 傷が塞がる | **医療ゲルを塗る**。深い傷ほど本数が要る |
| 明かり | 松明が燃え尽きる | **セルが減る**。消せば止まる。再充填できる |
| 呪い | 装備が外れない | **汚染ファームが動き続ける**。外せるが利点も失う |
| 鑑定 | 巻物を読む | **刻印を読む**。使えば分かる、殴られれば分かる |
| 死体 | 消える | **装備が落ちる**(人間系)。機械は部品を落とす |
| 扉 | 開く | **気圧が動く**。音がする。敵が起きる |
| 敵の増援 | 湧く | **監視に補足された結果**。原因がある |

**原則: 現象に必ず原因を持たせる。** 「なぜそうなるか」が説明できない挙動を置かない。
これが「SF 設定」と「SF らしさ」の差になる。

---

## 10.5 サイト固有の演出(コストの低い差別化)

生成器を4つ書くのは高コストだが、**同じ生成器でも印象は変えられる**。

| 手段 | 効果 | コスト |
|---|---|---|
| **地形グリフの差し替え** | 壁が `#` → 遺跡では `%`、尖塔では `|` | 極小 |
| **色調の差し替え** | サイトごとに壁と床の色を変える | 極小 |
| **入階メッセージ** | 「隔壁が軋んでいる。」「灰が降っている。」 | 極小 |
| **部屋の照明率** | 遺跡は常時照明の部屋が無い | 小 |
| **部屋の形** | 灰は矩形が崩れる。尖塔は縦長 | 中 |
| **区画テンプレートの出し分け** | 医療ベイは方舟、炉心区画は遺跡 | 小(データのみ) |

→ **`sites.json` にこれらを全部持たせる。** 生成アルゴリズムを4本書く前に、
   パラメータで到達できる差を全部使い切る。

## 10.6 やらないこと(アンチゴール)

差別化のために**壊してはいけないもの**を明示する。

| やらない | 理由 |
|---|---|
| **オートエクスプロア** | 電力と食料の経済が丸ごと無意味になる([[D-50]]) |
| **装備の自動最適化** | 「何を持つか」が本作の中心。自動化すると空になる |
| **サイトごとの別ルール** | 覚えることが増えるだけ。**同じルールが違う結果を出す**のが良い設計 |
| **強制イベント・カットシーン** | 物語はログ断片だけ([[D-45]])。手を止めさせない |
| **深度以外の難易度尺度** | 深度が唯一の尺度という本家の骨格を壊さない([[D-03]]) |
| **セーブスカム可能な設計** | 乱数状態を保存に含める方針を維持 |
| **リアルタイム要素** | ターン制の純度を保つ。昼夜もゲームターン基準 |

---

## 10.7 「Angband の骨格だ」と「Angband ではない」を両立させる

| 触って最初に分かること(骨格) | 30分後に分かること(差別化) |
|---|---|
| `@` が `#` の間を歩く | 扉を開けると気圧が動く |
| 深度が唯一の尺度 | サイトによって必要な装備が違う |
| 死んだら終わり | 撤退の理由が HP だけではない |
| 未鑑定のアイテムがある | 刻印を覚えると全部に効く |
| 速度が最重要 | 低重力では速いが弱い |

**最初の5分は完全に Angband であるべき。** 差別化は、
プレイヤーが骨格を理解した後に効き始めればよい。
逆順にすると「よく分からないゲーム」になる。

---

## 10.8 検証方法

差別化は主観になりやすいので、**測れる形**にする。

| 指標 | 測り方 | 合格ライン |
|---|---|---|
| サイトごとの死因分布 | 自動プレイをサイト別に集計 | **サイトごとに最頻死因が違う** |
| サイトごとの到達深度 | 同上 | 極端な差が無い(どれも成立している) |
| 環境ダメージの割合 | 総被ダメに占める環境の比率 | 15〜35%(低すぎ=飾り、高すぎ=理不尽) |
| 撤退の理由 | 母船帰還時の状態を記録 | HP 以外の理由が半分以上 |

M3 の受け入れ基準「4サイトそれぞれが明確に違う遊びになっている」は、
**上の指標で判定する**([[D-53]])。

計測は `node src/tests/autoplay.js --metrics --runs 60` で行う。

### M3b 時点の実測 (60ラン/サイト)

| サイト | 踏破率 | 環境ダメ比 | 最頻死因 | 撤退理由(HP以外) |
|---|---|---|---|---|
| 方舟 | 8% | 77% | 減圧 | 42%(気密不足が最多) |
| 灰の地表 | 12% | 16% | 掃引機 | 33% |
| 異星遺跡 | 1% | 3% | 虚空追い | 80%(被曝・灯り) |
| 尖塔 | 0% | 0% | 企業保安 | 100%(監視) |

**達成できたもの**: サイトごとに最頻死因が違う。
撤退理由もサイトごとに別の形をしている(方舟=気密、遺跡=被曝と灯り、尖塔=監視)。
**これは4サイトが違う圧をかけていることの、最も直接的な証拠**になっている。

**まだ達成できていないもの、およびその理由**:

1. **環境ダメ比が尖塔0% / 遺跡3%**。これは §8.7 の
   「**尖塔だけ環境が安全**」という設計と正面から矛盾する。
   指標のほうが4サイトの設計より先に書かれている。→ `[[Q-19]]`
2. **踏破率が遺跡・尖塔で0〜1%**。この2つは深度10/20 から始まるので、
   自動プレイヤーが**その深度に見合う装備を買えない**まま入って死ぬ。
   自動プレイヤーは店で最初に買える物を買うだけで、性能を比較しない。
   サイトの難易度ではなく**測定器の限界**を見ている。→ `[[Q-20]]`
3. **方舟の環境ダメ比は測るたびに 48〜77% と動く**。真空を避けて歩けるかは
   経路取り次第で、自動プレイヤーの賢さがそのまま数字になる。
   **この指標で方舟の調整の可否は判定できない**。→ `[[Q-20]]`

> 数字を鵜呑みにしないこと。上の4行のうち、**再現性があるのは最頻死因と撤退理由の内訳だけ**。
> 踏破率と環境ダメ比は、いまのところ自動プレイヤーの性能を測っている。

計測で見つかり、実際に直したもの:
遺跡の生成失敗25%(`[[D-63]]`)、方舟の減圧偏重(`[[D-62]]`)、
新規ランが方舟から始まって窒息する問題(`[[D-61]]`)、
監視の警戒度が階を移っても下がらない問題。
