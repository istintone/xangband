# 7. 最終ゴール設計

> **この文書が決めるのは「なぜ深度100まで潜るのか」**。
> 実装は M4 だが、**M3 のサイト設計を制約する**ので先に確定させる。
> 4サイトを作っても、1サイトだけ潜れば勝てるなら 4サイトは無意味になる。

---

## 7.1 設計上の問題

Angband の最終目標は「深度100 で Morgoth を倒す」の一点で、それで完成している。
本作は 4サイト構造を足した([[D-03]])。ここに設計上の問題が生まれる。

> **4サイトあるのに、1サイトだけ潜って勝てるなら、他の3サイトは飾りになる。**

サイトを「同じゲームの見た目違い」にしないためには、
**勝利条件そのものに4サイトを組み込む**必要がある。

### 却下した案と理由

| 案 | 却下理由 |
|---|---|
| 各サイトに鍵アイテムを置き、4つ集めると門が開く | **お使いになる**。Angband の「潜れば潜るほど強くなる」一本の軸を壊す |
| サイトごとに別のボスを置き、4体倒すと勝ち | ボス戦が4回に薄まる。深度100 の一点集中という本家の緊張が消える |
| サイトを選ぶと難易度だけが変わる | サイトが実質1つになる。作る意味がない |
| 深度100 到達を4サイトそれぞれで要求する | 単純に4倍の作業。誰もやらない |

---

## 7.2 採用する構造 ― 環境が門になる ([[D-44]])

**深度80以降(《起源》)では、4つの環境ハザードが同時に発生する。**

各サイトの最深部で得られる **《適合》** が、それぞれ1つのハザードへの恒久耐性を与える。
4つ揃わないと、深度80より下には**留まれない**(数ターンで死ぬ)。

```
漂流艦《方舟》 最深部  →  《適合:真空》   減圧が無効になる
灰の地表      最深部  →  《適合:放射》   被曝が無効になる
異星遺跡      最深部  →  《適合:汚染》   生体汚染が無効になる
超高層《尖塔》 最深部  →  《適合:監視》   監視網に補足されなくなる
                            ↓
                        深度80〜100 《起源》へ
```

### なぜこの形か

1. **お使いにならない。** 《適合》は「集めるアイテム」ではなく、
   そのサイトを潜り切った結果として身体が変わる。目的地はあくまで深度。
2. **4サイトそれぞれに「最後まで潜る理由」ができる。** どれも中途半端では終われない。
3. **環境システム(§[[doc:environment]])と直結する。** 新しい機構を足さず、
   既にある軸を勝利条件に接続するだけで済む。
4. **順序が自由。** どのサイトから始めても、どの順で終わってもよい。
   Angband の「自分のペースで潜る」自由を壊さない。
5. **ハードゲートは1箇所だけ。** 深度79までは完全に自由に潜れる。
   本家の「行けるが死ぬ」を最大限保つ。

### 《適合》の取得条件

各サイトの**担当深度レンジの最深階にいるユニーク**を倒すと得る。

| サイト | 深度レンジ | 最深ユニーク | 得られる適合 |
|---|---|---|---|
| 漂流艦《方舟》 | 1–40 | 深度38〜40 | 真空 |
| 灰の地表 | 1–30 | 深度28〜30 | 放射 |
| 異星遺跡 | 10–60 | 深度57〜60 | 汚染 |
| 超高層《尖塔》 | 20–80 | 深度77〜80 | 監視 |

- 最短ルートは **灰(30) → 方舟(40) → 遺跡(60) → 尖塔(80)**。自然に難易度が上がる。
- 尖塔の最深部が深度80 なので、**そこがそのまま《起源》の入口**になる。

## 7.3 《起源》とは何か

> **ネタバレ (spoiler level 3)。** ログ断片で少しずつ開示し、直接説明しない。

### 大断絶(The Severance)の正体

《起源》は**自己増殖する建造系**である。異星のものでも人類のものでもない。
**両方より前にあり、両方を作った。**

- 異星遺跡は《起源》の**初期の出力**。異星文明が作ったのではなく、
  《起源》が作ったものを異星文明が使っていた。
- 人類はそのうちの一基を見つけ、使い、拡張した。漂流艦も尖塔もその産物。
- **大断絶は故障ではない。** 《起源》が与えられた指示を完了し、
  **次の工程に移った瞬間**だった。人類は工程の一部だったので、切り離された。

### だから4サイトは同じものに見える

docs/00 §0.2 の「断絶より前に作られたものは、どれも同じ設計思想の痕跡を持っている
―― 異星の遺跡でさえも」は、この事実の伏線。
プレイヤーは 4サイトを潜るうちに、**同じ構造・同じ記号・同じ壊れ方**に気づいていく。

### 開示の設計

**説明しない。** ログ断片(`lore.json`)で断片的に置く([[D-45]])。

| 段階 | 開示するもの | 置き場所 |
|---|---|---|
| 深度 1–20 | 断絶前の日常。何かが起きたことだけ | 全サイト |
| 深度 20–45 | サイト同士の共通点への言及。技師の疑問 | 各サイト固有 |
| 深度 45–70 | 《起源》の存在。それが「作っている」こと | 遺跡・尖塔 |
| 深度 70–99 | 大断絶が完了であって故障でないこと | 起源 |
| 撃破後 | 次の工程が何だったのか | 勝利画面 |

- ログ断片は**拾って読む消費されないアイテム**。母船の格納庫に蓄積する。
- 全部集めなくても勝てる。**集めた者だけが意味を知る。**

## 7.4 深度80〜100 の構造

《起源》は他のサイトと違い、**部分的に固定**する(docs/02 §2.3 の例外)。

| 深度 | 内容 | 生成 |
|---|---|---|
| 80–89 | **接続層**。4サイトの地形が混ざって現れる | 非永続。生成器をフロアごとに切替 |
| 90–97 | **中枢層**。地形が破綻していく(非ユークリッド) | 非永続。歪んだ生成 |
| 98 | **静止層**。敵がいない。ログ断片だけがある | **固定** |
| 99 | 《門番》 THE WARDEN | **固定** |
| 100 | 《起源》 THE ORIGIN | **固定** |

### 深度98 ―― 何もない階
敵もアイテムも無い。ログ断片が数個あるだけ。
**直前に「静かにさせる」ことで、99・100 の重さを作る。**
Angband の深度100 が唐突に始まるのに対し、ここは意図的に間を置く。

### 《門番》(深度99)
- 単体。護衛なし。**逃げない、回復しない、後退しない。**
- 4つの環境ハザードを**攻撃として**撃ってくる。
  → 《適合》を持っていれば無効。持っていない状態では絶対に勝てない。
  → **《適合》の意味がここで最終確認される。**
- 倒すと深度100 への降下シャフトが開く。

### 《起源》(深度100)
- **形が定まらない。** ターンごとにグリフと攻撃属性が変わる。
- 段階制: HP が閾値を割るごとに**周囲の地形を作り替える**(建造系だから)。
- 護衛は生成しない。**《起源》自身が地形を敵に変える。**
- 逃げ場を作らないのではなく、**逃げ場を作り続ける**(通路が生える)。
  プレイヤーが有利になるとは限らない。

## 7.5 勝利と、その後

### 勝利条件
**深度100 で《起源》を撃破し、昇降機で母船まで戻る。**

- 撃破した瞬間ではなく、**帰還して初めて勝利**とする(本家と違う点)。
  → 撃破後に「帰り道」が残る。全力を使い切った状態で戻る緊張がある。
- 帰還中は《起源》の崩壊が進行し、**深度が上がるたびに階が壊れていく**。
  - 昇降機は一度に **10階ぶん**上がる ([[D-70]])。階と階の間の構造は既に落ちている。
    1階ずつ登らせると、それは緊張ではなく作業になる。
  - 崩壊の圧は**温度**でかける ([[D-71]])。ここまで来たプレイヤーは《適合》を
    4つ持っているので、減圧・被曝・汚染・監視はどれも効かない。
    温度は《適合》の対象外で、遮蔽と耐性で凌げる。
- 母船に着いた時点で勝利画面。

### 勝利画面が出すもの
- 到達記録(ターン数・レベル・撃破ユニーク・収集ログ断片)
- **収集したログ断片の数に応じて、次の工程の内容が段階的に出る**
  → 全部集めた者だけが完全な結末を読む
- 記録は `xangband.scores` に「勝者」として残る

### 勝利後
- そのランは終わる(パーマデス。勝っても続かない)。
- 【暫定】より深い《起源》(深度100超)を用意するかは M5 で判断する([[Q-16]])。

## 7.6 進行の骨格(プレイヤーが辿る道筋)

```
深度 1      母船で装備を整え、灰 or 方舟へ降りる
深度 1–15   基本装備を揃える。刻印を学ぶ。死因の大半はここ
深度 15–30  灰を潜り切る → 《適合:放射》
深度 30–40  方舟を潜り切る → 《適合:真空》
深度 40–60  遺跡を潜り切る → 《適合:汚染》      ← 電脳層(M4)が使えるようになる
深度 60–80  尖塔を潜り切る → 《適合:監視》
深度 80–97  《起源》へ。4つの環境が同時に襲う
深度 98     静止層
深度 99     《門番》
深度 100    《起源》 → 帰還
```

- **想定プレイ時間**: 1ラン 15〜40時間(初回)。本家 Angband と同程度。
- **想定死亡回数**: クリアまでに 20〜100 ラン。序盤で死ぬのが普通。

## 7.8 ログ断片の実装 ([[D-67]])

正本は `src/data/lore.json`。docs には代表例だけを置く(CLAUDE.md §3)。

```
{ id, title, stage, sites, depthMin, depthMax, text, spoiler }

stage    … 1:断絶前の日常 / 2:サイト同士の共通点 / 3:《起源》の存在 /
           4:断絶が完了であること / 5:次の工程(撃破後のみ)
sites    … 出うるサイトの id 配列。null なら全サイト
depthMin/Max … 出る深度の範囲。§7.3 の開示表に対応する
```

- 床に落ちている**消費されないアイテム**として拾う。所持重量を持たない。
- 拾った時点で全文が読め、**所持品には入らない**。
  格納庫へ移す手順すら要らない ―― 持ち歩く判断をさせないことが目的なので、
  最初から持たせなければよい。読み物で所持枠を圧迫しない。
- 収集済みの id は `W.loreFound` に溜まり、**セーブとスコアに残る**。
- `stage: 5` は床に置かない。**勝利画面でのみ、収集数に応じて開示する**。

### 収集数と結末の解像度

| 収集率 | 勝利画面で読めるもの |
|---|---|
| 〜30% | 撃破の事実だけ |
| 30〜60% | 次の工程が始まっていること |
| 60〜85% | 次の工程が何であるか |
| 85%〜 | 人類がその工程のどこに位置するか(完全な結末) |

**全部集めなくても勝てる。集めた者だけが意味を知る**(§7.3)。

## 7.9 開発用の起動オプション ([[D-66]])

1ラン15〜40時間の通しプレイを実装のたびに繰り返せないので、
**終端だけを繰り返し通せる入口**を用意する。

```
index.html?dev=depth:99,adapt:all,gear:deep
   depth … その深度から始める
   adapt … 《適合》を与える (all / vacuum,radiation,...)
   gear  … 深度相応の装備一式を持たせる
   lore  … ログ断片の収集率を指定する (勝利画面の分岐確認用)
   god   … 耐久と武器を底上げする。**終端の機構だけを確かめるための下駄**
```

`gear` は「実際に店に在るもの」しか買わない。深部の装備がまだ存在しない現状では
これで裸同然になるので、機構の確認には `god` を併用する。
`god` を使った計測は**バランスの判定には一切使えない**。

- **開発モードで始めたランはスコアに残さない。** `W.devRun` を立て、
  勝利画面にも「開発モード」と明示する。記録の意味が壊れるため。
- 通常のプレイからは到達できない(`?dev=` を明示的に付けたときだけ)。
- 手触りの検証はこれでは代替できない。通しプレイは M5 で行う。

## 7.7 この設計が守っていること

| 本家の性質 | 本作での扱い |
|---|---|
| 深度が唯一の難易度尺度 | **維持**。《適合》も深度で得る |
| どこまでも潜れる(死ぬだけ) | **維持**。ハードゲートは深度80 の1箇所のみ |
| 目的地が1つ | **維持**。深度100 の《起源》一点 |
| 物語は説明されない | **維持**。ログ断片のみ。強制イベントを作らない |
| パーマデス | **維持**。勝っても続かない |

| 本作で足したもの | 狙い |
|---|---|
| 4サイトを潜り切る必然性 | サイトを飾りにしない |
| 環境が勝利条件に接続する | 新機構を足さずに構造を作る |
| 撃破後の帰還 | 最後の緊張を作る |
| 収集度で結末の解像度が変わる | 探索の報酬を物語にも置く |
